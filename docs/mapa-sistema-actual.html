Fixes de Seguridad Aplicados

Críticos (C1-C5)

C1 — Strip datos sensibles

empleados/usecases/profiles.ts — Salary, bankAccount, bankName, emergencyContactPhone se strippan para roles bajos (receptionist, housekeeper, maintenance).

C2 — Validar employeeId contra hotel

empleados/usecases/validate-employee.ts (nuevo) — Valida que employeeId pertenece al mismo hotelId antes de crear contratos, documentos, vacaciones o evaluaciones.

C3 — Webhook biométrico

attendance/controller.ts — Valida hotelId contra ATTENDANCE_BIOMETRIC_HOTEL_ID. Previene clock-in cross-tenant con key robada.

C4 — Payslip numbers atómicos

payroll/usecases/payslip-number.ts — Optimistic locking con 3 reintentos. Previene números duplicados bajo concurrencia.

C5 — Roles por nivel

usuarios/controller.ts — Receptionist solo puede crear housekeeper/maintenance. Default receptionist para non-superAdmins.
