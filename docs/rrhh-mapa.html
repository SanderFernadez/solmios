Por qué no está conectado

El núcleo operativo (Empleados ⇄ Asistencia → Nómina → Caja) está cableado y funcionando. Las fracturas están en los bordes: donde un módulo debería alimentar a otro pero el puente no se construyó o se rompió.

falta
Reclutamiento → Empleados
candidato ✕ contratación ✕ expediente

No hay módulo de selección: vacantes, candidatos ni pipeline. El alta del empleado se hace 100% a mano en Empleados. Es el único módulo core de Odoo que no existe.

enlace débil
Equipo ⇄ Empleados
Users ⇢ débil ⇠ employee_profiles

Son dos entidades distintas (cuenta de usuario vs. expediente) ligadas solo por userId. Crear un usuario en Equipo no genera su expediente en Empleados. Sin UI que los vincule automáticamente.

roto
Organigrama (dentro de Empleados)
backend /org-chart ✓ · frontend ✕ no dibuja

El backend ya devuelve el árbol jerárquico de departamentos por /org-chart, pero el front no lo renderiza. Reporte del cliente #199: “el organigrama no hace nada”. Fix de frontend, la data ya existe.

falta
Reembolsos de empleado → Caja
gasto del empleado ✕ reembolso

Existe /gastos pero es el gasto operativo del hotel, no el reembolso al empleado (viáticos, compras). Gap conceptual: en Odoo es el módulo Expenses ligado a la nómina.

incompleto
Dashboard ← alimentadores
data ✓ existe · widgets ✕ no se muestran

El dashboard vive pero le faltan 9 widgets que pide el cliente: cumpleaños del mes (#196), colaboradores en vacaciones (#197), resumen de asistencia (#198), top desempeño (#202), pendientes (#205). El backend ya expone casi todo.

parcial
Portal de autoservicio
app móvil PIN ✓ · portal web ✕

El endpoint employee-profiles/me y el login PIN de la app móvil existen, pero no hay portal web donde el empleado vea sus recibos, pida vacaciones o consulte su ficha.
